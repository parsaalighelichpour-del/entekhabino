# انتخابینو 🎯

اپلیکیشن ساده و فارسی برای انتخاب تصادفی با چرخ گردان؛ مناسب موبایل و قابل بسته‌بندی در اپ اندروید با WebView.

## اجرا
فایل `index.html` را در مرورگر باز کنید. همه‌چیز در یک فایل است و نیاز به نصب کتابخانه یا اینترنت ندارد.

## قابلیت‌ها
- چرخ انتخاب با انیمیشن طبیعی و انتخاب تصادفی
- افزودن و ویرایش گزینه‌ها (هر گزینه در یک خط)
- ذخیره گزینه‌ها و تاریخچه روی همان دستگاه
- طراحی واکنش‌گرا برای موبایل

## دانلود پروژه
از صفحه مخزن، دکمه **Code → Download ZIP** را بزنید.

## تبدیل به APK
این پروژه یک وب‌اپ مستقل است. برای تبدیل آن به APK، یک سازنده APK با قابلیت **WebView / HTML app** انتخاب کنید و فایل `index.html` را به‌عنوان صفحه محلی (local asset) وارد کنید. گزینه اجرای آفلاین/local HTML را فعال کنید. سپس نام برنامه را «انتخابینو» و آیکن دلخواه را تنظیم و خروجی APK بگیرید.

> توجه: فایل APK امضاشده تولید نشده؛ این مخزن سورس برنامه است.
